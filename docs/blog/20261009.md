A static site with quizzes on different topics, built as a Nuxt 4 SPA and deployed to GitHub Pages.

Quizzes are grouped by topic with a sidebar index; one page = one quiz. Three question types are supported: single choice, multiple choice, and text input. Questions, answers, and explanations support markdown, images, and LaTeX formulas (KaTeX, rendered at build time).

Each quiz can have a timer for the whole test or per question, with a progress bar on top. Scoring is 0/1/2, and the results page breaks down every answer. Questions and options are shuffled on every run, and attempts are stored locally: the Stats page shows per-quiz history charts with a reset button. The "I don't know" button flags a question, and flagged questions are collected on a review page with correct answers and explanations.

Quiz sources are plain markdown files (`content/tests/*.md`), and the build script parses them, renders KaTeX/markdown to HTML, and obfuscates the payload (XOR + Base64 with a random per-build key) before Nuxt generates static pages. There's also an LLM prompt that converts any file or web page into a quiz in the supported format.

Everything runs inside Docker (`make install`, `make build`, `make test`), and pushes to `main` deploy to GitHub Pages via GitHub Actions.

Stack: Nuxt 4.6, TypeScript, Tailwind CSS 4, markdown-it, KaTeX, Vitest, Docker Compose.
