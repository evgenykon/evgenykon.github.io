I've launched a new pet project — an interactive **Circle of Fifths** web application for musicians and music learners.

**Try it live:** [evgenykon.github.io/quinto-circle](https://evgenykon.github.io/quinto-circle/)

Built with **Nuxt 4**, **Vue 3** and **TypeScript**, the app visualizes the Circle of Fifths with real-time audio playback and harmonic analysis.

### Features

- **Key & tonality selection** — major and minor keys with full harmonic analysis
- **Scale & chord display** — see notes, intervals, and chords for any key
- **Chord progression patterns** — built-in progressions for classical, pop, jazz, and more
- **Instrument picker** — switch between piano, guitar, and organ sounds
- **Playback engine** — chord or arpeggio style with tempo control and metronome
- **Interactive visualization** — click any key on the circle to hear and explore

### Tech

- **Framework:** Nuxt 4 with Vue 3, TypeScript
- **Audio:** Web Audio API with Tone.js
- **Styling:** Custom CSS
- **Deploy:** GitHub Actions → GitHub Pages
