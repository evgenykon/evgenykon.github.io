I've built a [Three Body Problem simulation](https://evgenykon.github.io/three-body-problem/) — an interactive physics demo that visualizes the chaotic gravitational motion of three bodies. Built with Vue 3 + Vite + TypeScript, featuring configurable masses, positions, and velocities. Check the [source on GitHub](https://github.com/evgenykon/three-body-problem).
