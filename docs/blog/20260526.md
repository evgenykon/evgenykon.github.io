I've released **version 2** of my browser-based Conway's Game of Life implementation — **Life (fork)**.

**Try it live:** [evgenykon.github.io/life-game-fork](https://evgenykon.github.io/life-game-fork/)

![ui](https://evgenykon.github.io/life-game-fork/screen.52.07.png)

Built with vanilla JavaScript and HTML5 Canvas, the app now supports extended rules beyond the classic B3/S23. The UI uses **Effus UI** v1 — my own lightweight CSS template ([npm](https://www.npmjs.com/package/effus-ui)).

### What's new in v2

- **Multiple rule sets** — choose from Life, HighLife, Day & Night, Seeds, Maze, Coral, and more
- **Custom rules** — define your own Birth/Survival patterns (e.g., B3/S23)
- **Drawing tools** — draw cells manually on the grid
- **Glider gun** — one-click spawning of the Gosper glider gun
- **Grid & controls** — start/stop, step-by-step, random fill, and clear
- **Performance** — optimized rendering for larger grids
