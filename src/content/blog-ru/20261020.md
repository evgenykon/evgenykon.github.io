У пеших прогулок есть неприятное свойство: смотришь в телефон вместо города. Поэтому я сделал Android-аудиогид,
который работает наоборот — вы идёте, а когда входите в зону точки, она начинает рассказывать про место.
Экран выключен, руки свободны.

Сайт: **[evgenykon.github.io/travel-guide](https://evgenykon.github.io/travel-guide/)** ·
Код: **[github.com/evgenykon/travel-guide](https://github.com/evgenykon/travel-guide)**

## Как это работает

- **Карта** — MapLibre с векторными тайлами OpenFreeMap. Тап по точке открывает карточку с названием,
  OSM-объектом, координатами и высотой; долгое нажатие на карту создаёт новую точку, есть кнопка «точка здесь».
- **Геозоны в 10 метров** — foreground-сервис с постоянным уведомлением следит за позицией и проговаривает
  описание в момент входа в зону, в том числе с выключенным экраном. Каждая точка озвучивается один раз; повтор —
  из истории. Перед стартом трекинга чеклист проверяет разрешения, фоновую геолокацию, уведомления, ограничения
  батареи — и настройки автозапуска на Xiaomi/MIUI с прямыми ссылками в нужный раздел.
- **Голос** — Yandex SpeechKit: выбор голоса и скорости, аудио кэшируется на устройстве.
- **Описания** — вручную или сгенерированные через OpenRouter. Сначала приложение само определяет OSM-объект,
  адрес по Nominatim, город и страну и подставляет их в промпт, чтобы модель не путала места с одинаковыми
  названиями. Координаты никогда не проговариваются. Шаблон промпта редактируется.
- **Маршруты, история, импорт/экспорт** — маршруты со своими точками, история входов и прослушиваний, экспорт и
  импорт JSON, который сливается по имени и координатам без дублей.

Всё живёт на устройстве: Room для точек/маршрутов/истории, DataStore для настроек, EncryptedSharedPreferences
для ключей. После переустановки контент возвращается из авто-бэкапа Android — ключи намеренно нет.

## Редактор маршрутов без бэкенда

[Браузерный редактор](https://evgenykon.github.io/travel-guide/editor.html) — обычная страница: та же карта
MapLibre, перетаскивание точек, радиус срабатывания, определение адресов, генерация описаний через OpenRouter,
импорт/экспорт в формате `BackupFile` самого приложения. Ключ API живёт в памяти страницы (по желанию — в
`sessionStorage` вкладки), серверу его утечь некуда.

## CI

Пуш в `main` → юнит-тесты, линт, debug APK артефактом и обновляемый `dev-latest` пре-релиз; тег `vX.Y.Z` →
подписанный APK релиза и GitHub Release. Сайт публикуется из `site/` отдельным workflow.

Установка: **[releases](https://github.com/evgenykon/travel-guide/releases)** (APK, Android 8.0+; SpeechKit и
OpenRouter тарифицируют по факту, само приложение бесплатное).
