Я читаю много FB2 — это фактически формат по умолчанию для любой русской электронной библиотеки — и каждая
читалка, которую я пробовал, либо игнорировала мои заметки, либо теряла позицию чтения после обновления, либо
была веб-обёрткой вокруг чего-то другого. Поэтому я написал свою: **My Books**, читалка FB2 для Android и macOS
с общим ядром.

Репозиторий: **[github.com/evgenykon/my-books](https://github.com/evgenykon/my-books)**

## Идея: один парсер, а не два

Интересна тут не UI. Интересно то, что обе программы читают книгу через *один и тот же* код. Книга один раз
разбирается в плоский список блоков (`Block`), а позиция чтения — это просто `(индекс блока, смещение в
символах)`. Ни DOM, ни attributed strings в ядре, никаких платформенных сюрпризов парсинга: позиция, сохранённая
на телефоне, открывается на том же слове на маке, а процент считается в одном месте (`ReadingProgress`).

```
shared/      ядро Kotlin Multiplatform: парсер FB2, модель книги, прогресс чтения
androidApp/  Kotlin + Jetpack Compose
macos/       SwiftUI + CoreText (SwiftPM, ядро как Shared.xcframework)
```

## Что делает ядро

- **`Xml.kt`** — терпимый к ошибкам XML-ридер без зависимостей, потому что реальные FB2 из библиотек ломаются
  куда чаще, чем хотелось бы. Кодировки: UTF-8, windows-1251, KOI8-R, Latin-1, UTF-16 плюс именованные
  сущности (`&nbsp;`, `&mdash;`, …).
- **`Fb2Parser.kt`** — title-info (название, авторы, аннотация, обложка), тело книги (заголовки, абзацы,
  эпиграфы, стихи, картинки), оглавление из `section/title`, а тело `name="notes"` переносится в конец книги как
  «Примечания».
- **`Model.kt`** — `Book`, `Block`, `TocEntry`, `Position`, `ReadingProgress`.
- **Тесты** в `shared/src/commonTest`: парсинг, оглавление, индексы блоков, прогресс, декодирование cp1251 и
  UTF-8 с BOM.

## Android

Импорт через SAF (вообще без разрешений на хранилище), библиотека с прогрессом, удаление книги вместе с заметками.
Читалка пагинирует по *реальной* раскладке текста через `TextMeasurer`, в шапке — книга, автор, «стр. N из M»,
процент; своя текстовая панель для **Копировать** и **В заметку** — цитата берётся прямо из выделения.

## macOS

Импорт через `fileImporter`, пагинация через `CTFramesetter`, навигация стрелками, пробелом или свайпом.
Выделение нативное (`textSelection(.enabled)` + ⌘C), плюс контекстное меню абзаца с «Копировать абзац» и
«Добавить заметку». Семейство шрифта, размер, межстрочный интервал, поля, тема (светлая / сепия / тёмная) и
выравнивание по ширине работают одинаково на обеих платформах.

## Сборка

Локальных сборок Gradle нет — обе платформы собираются в GitHub Actions:

- **Android** — `:shared:testDebugUnitTest` + `:androidApp:assembleDebug`, APK в артефакте `mybooks-debug-apk`;
- **macOS** — Kotlin/Native фреймворки линкуются в `Shared.xcframework`, дальше SwiftPM собирает приложение.

В этом и смысл архитектуры: рискованная и багопроизводящая половина (парсинг, позиции, прогресс) — один
Kotlin-модуль с тестами, а оба UI — тонкие оболочки над ним.
