Любой спор с плоскоземельщиком кончается одинаково: те же двадцать доводов по кругу и ссылка на Википедию,
которую никто не открывает. Поэтому вместо спора я сделал сайт, который ставит довод и опровержение рядом —
**Плоская Земля: доводы и контр-доводы**.

Сайт: **[evgenykon.github.io/flat-earth](https://evgenykon.github.io/flat-earth/)** ·
Код: **[github.com/evgenykon/flat-earth](https://github.com/evgenykon/flat-earth)**

## Две стороны, два режима чтения

- **Светлая сторона** (`/light/`) — доводы плоскоземельщиков. Раскрываем довод — научные контр-аргументы сразу
  тут же, без лишних кликов.
- **Тёмная сторона** (`/dark/`) — атаки на науку из первоисточников, с дословными цитатами и указанием авторов.
  Контр-аргументы **скрыты**, пока не нажать кнопку «Я хочу контр-аргументы» вверху страницы: сначала читаешь
  довод так, как его задумал автор, и только потом переключаешься.

Тёмная сторона собрана из трёх книг — Роуботэм, *Zetetic Astronomy* (1865); Карпентер, *One Hundred Proofs That
the Earth Is Not a Globe* (1885); Дюбэ, *200 Proofs Earth is Not a Spinning Ball* (2014). Тексты в public domain,
поэтому скрипт парсит их, разбивает на нумерованные доводы, раскладывает по темам и подставляет тематические
контр-аргументы (`scripts/generate-dark.mjs`), а затем переводит всё на русский через публичный эндпоинт
перевода (`scripts/translate-dark.mjs`). Файлы, отредактированные руками, скрипты не трогают.

## Контент — это просто markdown

Добавить довод — один файл: frontmatter (`title`, `claim`, `argument`, `category`, `order`) плюс текст
контр-аргументов в теле. `git push` → GitHub Actions собирает → довод в эфире. Ни CMS, ни базы данных.

Сам сайт — Astro + Tailwind с собственной песочной палитрой (без дефолтной темы), публикуется на GitHub Pages из
ветки `main`.

## Зачем это вообще

Не чтобы кого-то переубедить — цель уже и полезнее: показать, *почему* каждый довод не работает, с оригинальной
формулировкой перед глазами. Это ещё и неплохая практика чтения первоисточников: доказательства XIX века —
занятная смесь геометрии, плохих измерений и абсолютной уверенности.
