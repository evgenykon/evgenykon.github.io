Walking tours have one annoying property: you look at the phone instead of the city. So I built
an Android audio guide that does the opposite — you walk, and when you enter a point's zone it
starts telling you about the place, screen off, hands free.

Site: **[evgenykon.github.io/travel-guide](https://evgenykon.github.io/travel-guide/)** ·
Code: **[github.com/evgenykon/travel-guide](https://github.com/evgenykon/travel-guide)**

## How it works

- **Map** — MapLibre with OpenFreeMap vector tiles. Tap a point for a card with its name, OSM
  object, coordinates and elevation; long-press the map to create a new point, or drop one at your
  current location.
- **10-metre geofences** — a foreground service with a persistent notification watches your
  position and narrates the description the moment you step into the zone, including with the
  screen off. Each point is narrated once; re-play it from History. Before tracking starts a
  checklist verifies permissions, background location, notifications, unrestricted battery — and
  autostart/battery settings on Xiaomi/MIUI, with deep links straight into the right settings
  screen.
- **Voice** — Yandex SpeechKit, selectable voices and speed, audio cached on the device.
- **Descriptions** — written by hand, or generated through OpenRouter. The app resolves the OSM
  object, the Nominatim address, the city and the country first and injects them into the prompt,
  so the model doesn't confuse two places with the same name. Coordinates are never spoken out
  loud. The prompt template is editable.
- **Routes, history, import/export** — routes with their own points, zone and playback history,
  JSON export/import that merges by name and coordinates without duplicates.

Everything lives on the device: Room for points/routes/history, DataStore for settings,
EncryptedSharedPreferences for keys. After a reinstall the content comes back from Android
auto-backup — the keys deliberately don't.

## A route editor without a backend

[The browser editor](https://evgenykon.github.io/travel-guide/editor.html) is a plain page: the
same MapLibre map, drag points, set radius, resolve addresses, generate descriptions through
OpenRouter, import/export the app's own `BackupFile` format. The API key stays in page memory (or,
on request, in the tab's `sessionStorage`) — there is no server to leak it.

## CI

Push to `main` → unit tests, lint, debug APK as an artifact and a rolling `dev-latest`
pre-release; a `vX.Y.Z` tag → signed release APK and a GitHub Release. The site is published from
`site/` by a separate workflow.

Install: **[releases](https://github.com/evgenykon/travel-guide/releases)** (APK, Android 8.0+;
SpeechKit and OpenRouter bill you per use, the app itself is free).
